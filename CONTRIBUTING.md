# Contributing

Bug reports and narrowly scoped pull requests are welcome. The canonical
project remains maintained and released solely by `zatopiony69-prog`; submitting
a pull request does not make a fork or modified build an official release.

Before opening a pull request:

1. Discuss material behavior changes in an issue.
2. Keep the change focused and add tests for safety-policy logic.
3. Run the Release build and test suite.
4. Explain gameplay, compatibility, and cleanup implications.
5. Certify that you have the right to submit the contribution under GPL-3.0-only.

The maintainer may decline changes that broaden permissions, add telemetry,
introduce external services, weaken cleanup guarantees, or make the plugin
harder for server owners to audit.
